Fun with Filters

1.1  Convolutions from Scratch

We can implement convolutions using for loops. It can be done with 4 for loops, and then more efficiently with 2 for loops. They both however, have the same setup steps:

  1. Pad the input with zeros so the output is the same size as the input. The filter is centered on each pixel, so the padding is (filter_x - 1) // 2 before and filter_x // 2 after — split this way so even-sized filters still work.
  2. Allocate the output array at the original image size.
  3. Flip the filter with np.flip. This changes the operation from correlation, to convolution

From this point, this is how they differ:

The 4 loop implementation iterates over each row and column in the image A, which yeilds us each pixel. Then with each pixel, we iterate over each row and column of our filter, which applies each pixel of our filter to its corresponding section in the source image.

The two loop implementation takes advantage of numpy's vectorization. instead of iterating over the filter sequentially, it can apply the filter in just one operation.

All three run on the same 1206×1335 grayscale image with the same 9×9 box filter.

What is the reason for this loop discrepancy? The 4 loop iteration requires Image_Height * Image_Width * Filter_Height * Filter_Width operations, and every one of them runs in Python. With the 2 loop version, it keeps the first half of that equation, but the filter is applied as a single operation, so only Image_Height * Image_Width steps happen in Python and the rest are handed to numpy to run in C. Scipy is even faster still because it does not run any of those iterations in Python: the whole nested loop lives in compiled C, so it avoids the per-step interpreter overhead that even the 2 loop version pays once per pixel.

Boundary handling

I chose the same output size with zero padded boundaries. The benefits of this approach are its simplicity to implement, as well as preserving the dimensions of the image. A drawback, however, is that the edges become darkened, as you can see in the output images. Scipy does the same thing by default, since convolve2d uses boundary='fill' with a fill value of 0, so our outputs line up. It also offers 'symm' and 'wrap', which mirror or tile the image instead of filling it with black, but I did not implement those.

1.2  Finite Difference Operator

By taking partial derivatives in a direction, we can detect vertical and horizontal edges in an image. By taking the gradient, we can get edges in both directions.

However, since the image has discrete pixel values, it is not continuous and therefore not a differentiable function. To get around this, we can approximate the derivative using the finite difference operator. We can get the difference between the pixel we are targeting, and the one next to it, and the result should be a pretty good approximation. This is done in the code below.

With the 2 derivative approximations, we take the gradient magnitude, which is the square root of the sum of our squared approximations. This reconstructs an image with edges in both direction. The edges can appear soft, however, and include noise. The solution to this is binarization: Introducing a hard cutoff for a pixel value. Pixels below the cutoff are omitted, and pixels above the cutoff are scaled up to 1.

1.3  Derivative of Gaussian (DoG) Filter

The finite difference results in 1.2 were noisy, since every small change between neighboring pixels shows up as an edge. To fix this, we can first blur the image with a gaussian, which smooths out the noise, and then take the derivatives like before.

What differences between 1.2 and 1.3? 1.3 has much smoother edges, compared to the noise in 1.2. The gaussian aspect made the derivative estimations smoother, which lead to a better looking image.

Fun with Frequencies

2.1  Image Sharpening

To sharpen an image, you must first extract the low-frequency parts of the image, which can be done through a gaussian blur. With that gaussian blur, you can subtract the low frequencies from the base image, and you will be left with only the high frequencies. This however, is not the sharp image. We must add the high frequencies to the original image, and this produces the sharpened image.

The trick, is that this can all be combined into one filter, called the unsharp mask. Since the identity kernel returns the image unchanged, subtracting the gaussian from it gives a high pass filter, and adding that back to the identity gives identity + alpha * (identity - gaussian). Convolving with that single kernel does all three steps at once, and alpha controls how much of the high frequencies get added back.

Blur, then re-sharpen

We lose some frequency information when we blur an image that can not be fully recovered by applying the unsharp mask. The unsharp mask can only amplify the frequencies that are still in the image, so the edges that survived the blur come back with strong contrast, but the detail that was wiped out stays gone. You can see this around the helmet, where the boosted edge leaves a dark halo, while the face inside the cage is still soft. Sharpening is not the inverse of blurring.

2.2  Hybrid Images

A hybrid image is two images combined into one, where what you see depends on how far away you are. Up close, our eyes pick up the high frequencies, and from far away, only the low frequencies are visible. To make one, we low pass one image with a gaussian, high pass the other with the impulse minus a gaussian, and add them together. The images need to be aligned first, or the two never line up into one picture.

2.3  Gaussian and Laplacian Stacks

A gaussian stack is like a pyramid, but without the downsampling. Each level is the previous level blurred again with a gaussian, so every level stays the same size as the original. The laplacian stack is the difference between each level and the next, which leaves only the frequencies lost in that blur. Adding all the laplacian levels back together, plus the last gaussian level, gives back the original image.

2.4  Multiresolution Blending

To blend two images, we build a laplacian stack for each image and a gaussian stack for the mask. At each level, we combine the two laplacians using that level of the mask, then add all the levels back up. Since the mask gets blurrier at each level, the low frequencies blend over a wide area and the high frequencies over a narrow one, which hides the seam.

What I Learned

I learned about how combining different frequencies can create new, smooth images. Almost everything in this project came down to splitting an image into its low and high frequencies with a gaussian, and then deciding what to do with each part. Sharpening adds more of the high frequencies back, hybrid images take the low frequencies from one picture and the high from another, and blending mixes each band separately so the seam disappears. It also showed me that this only goes one way: once a blur throws frequencies away, no filter can bring them back.
